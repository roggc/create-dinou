# create-dinou

Command to create a dinou app. dinou is a minimal React 19 framework. dinou means 19 in catalan.

Use `npx create-dinou@latest my-app` to create a dinou app.

This is the [dinou](https://www.npmjs.com/package/dinou) module.

This is the [app](https://github.com/roggc/dinou-app) you will get by executing the command.
