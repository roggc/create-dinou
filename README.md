# create-react19-app

The command `npx create-react19-app@latest my-app` creates a **multi-page SSR React 19** app ready for development, either with **TypeScript or JavaScript** (if you want JavaScript instead of TypeScript, just replace extension of `src/page.tsx` file for `jsx` or `js`). Once created, run command `npm run dev` to start development or read the included `README.md` file in the project for more information. [This is the project](https://github.com/roggc/react19ssr) if you want to take a look at it first.

If you want to build a SPA (Single Page Application) without SSR (Server Side Rendering), then run the same command with the `--nossr` option: `npx create-react19-app@latest --nossr my-app`. It will create a project like [this one](https://github.com/roggc/react19).
