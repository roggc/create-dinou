# create-react19-app

This creates a React 19 app, with Server Functions and Server Components support. Run `npx create-react19-app@latest my-app` to create a React 19 app ready for development, either with Typescript or Javascript (if you want Javascript instead of Typescript, just replace extension of `src/app.tsx` file for `jsx` or `js`). Once created, run command `npm run dev` to start development or read the `README.md` file for more information.
